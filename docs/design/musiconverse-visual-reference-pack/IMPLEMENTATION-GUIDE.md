# Implementation-facing reference guide

## Environment and cinematic direction
Use **01** to establish the universe’s physical scale, material cues, light falloff, and palette. **02** defines the opening experience; **03** expresses the transition from exploration to focused creation. These are environmental references rather than UI templates. **04** is the primary composition target for the studio. **11** explores how a clearly distinct celestial setting can coexist with a consistent production workspace. Keep environmental light and detail around the work surface, never at the expense of contrast or timeline legibility.

## DAW structure and professional behavior
Use **05** as the main arrangement/usability benchmark, **06** for mixer organization, **07** for audio-processing controls, **09** for precise editing, and **10** for library discovery. These references prioritize familiar professional conventions: ruler and playhead, aligned track headers, functional region distinctions, routing, meters, numerical parameters, selection, and readable metadata. The product should retain those conventions while developing its own visual identity; do not reproduce a proprietary DAW screen.

## Assistant and shared design language
**08** defines the visual role of **SYLUNE**: an abstract, attentive, musically aware presence integrated into the session rather than a generic chat box or portrait. Preserve the distinction between a suggestion, a review action, and a completed change. **13** is the shared system board: dark mineral foundations, disciplined accent use, neutral readable typography, reliable control states, practical spacing, and a clear boundary between atmospheric environment and functional controls. Use **12** for an overview and the individual numbered images for detail.

All screens are visual concepts, not assertions that the product currently implements the depicted features. Names, values, and suggested actions are illustrative. Keep controls credible, legible, and restrained; reserve bloom for the environment, and never make color the sole carrier of state.
