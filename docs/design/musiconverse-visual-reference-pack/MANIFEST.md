# MusicOnVerse visual reference pack — manifest

All PNGs are original visual concepts for a fresh product direction. Interface details are illustrative references, not claims about existing functionality. Numbered image files are kept separate at full resolution; overview/contact boards are navigation aids.

| # | File | Purpose | Recommended use |
|---|---|---|---|
| 01 | `01-cosmic-moodboard.png` | Four distinct cosmic environment studies establishing celestial scale, materials, palette, depth, and light. | Primary environmental art direction; derive background and lighting principles, not UI layout. |
| 02 | `02-universe-opening.png` | Immersive first view, with restrained MusicOnVerse identity and a subtle studio entry. | Opening/launch experience, negative space, first-person scale, and minimal control treatment. |
| 03 | `03-studio-arrival.png` | Directional movement through the same universe toward a studio destination. | Transition/arrival concept; a visual metaphor only, not a specified implementation feature. |
| 04 | `04-immersive-studio.png` | Main cosmic studio with a legible arrangement and mixer in a distinctive environment. | Primary product-composition reference; balance atmosphere against production readability. |
| 05 | `05-arrangement-reference.png` | Dense, conventional professional DAW arrangement with tracks, regions, ruler, and transport. | Structural/usability benchmark for arranging; preserve familiar DAW information hierarchy without copying branding. |
| 06 | `06-mixer-reference.png` | Aligned channel strips, routing/effects, faders, meters, buses, and master. | Mixer scanning, channel grouping, and control alignment. |
| 07 | `07-plugin-reference.png` | EQ plug-in concept with graph, band nodes, parameters, and metering. | Precision, numerical legibility, and processing-window treatment. |
| 08 | `08-sylune.png` | SYLUNE’s abstract orbital presence beside a proposed vocal EQ adjustment. | AI-assistant visual identity and proposal/review states. Keep suggestions distinct from applied changes. |
| 09 | `09-detailed-editing.png` | Close arrangement/editor view focused on waveforms, selection, boundaries, and grid. | Detailed edit workflow; use when validating precision and editing density. |
| 10 | `10-sound-library.png` | Wide library browser with categories, search, filtering, sound metadata, and preview context. | Sound discovery, preset browsing, and scan-friendly list/card hierarchy. |
| 11 | `11-alternative-studio.png` | Same general studio purpose in a visually distinct ringed-planet setting. | Demonstrates environmental variation while retaining a recognizable production workspace. |
| 12 | `12-numbered-overview.png` | Editorial overview of references 01–11 with numbered captions. | At-a-glance orientation; use the corresponding source PNG for detailed inspection. |
| 13 | `13-design-language-board.png` | Shared palette, typography, states, region colors, meter/graph, materials, and layer separation. | Cross-screen visual system reference and practical design constraints. |
| — | `contact-sheet.png` | Quick-browse sheet of all thirteen numbered assets. | Fast inventory; not a substitute for individual source files. |
