# Reference-derived palette inventory

## Sampling and scope

The full-resolution PNGs **01–13** were retrieved from `docs/design/musiconverse-visual-reference-pack/` at commit `900f07330f463d26bde0cc1d4bd731945c4fffec` on remote branch `arena/e04204ac-onverse`, and reviewed individually alongside `MANIFEST.md` and `IMPLEMENTATION-GUIDE.md`. That source branch is not merged into this workbench branch; the reference originals are not bundled into the app or modified. The retained `artifacts/visual-reference-review-contact-sheet.jpg` is only a low-resolution overview. The inventory uses the swatches explicitly labelled on **13** as canonical hue anchors. Supporting shades retain the earlier approximate sRGB sampling record: each full-resolution image was reduced to 240×135, quantized to ten colours, and its dominant bins read with ImageMagick. This is a practical visual inventory, not a pixel-accurate extraction or a contrast certification.

**Use boundaries:** 13 is the shared system authority; 02 and selected portions of 01 guide cosmic atmosphere; 05 and 09 guide editing clarity and professional information hierarchy. 04 was reviewed for composition only and is not a palette source. 12 is an overview board, not a palette source. Images 06–11 were inspected for their respective mixer, processing, assistant, library, and alternate-environment roles. The source images are review material and were not modified.

## Semantic token mapping

The implementation in `tokens.css` keeps the sampled palette centralized:

- `--mvo-color-*` holds canonical/reference hue anchors and sampled signal supports.
- `--mvo-space-*`, `--mvo-surface-*`, `--mvo-panel-*`, and `--mvo-text-*` define the night foundation and readable work surfaces.
- `--mvo-atmosphere-*` and `--mvo-light-spill-*` reserve lower-alpha colour for the scene and panel edge lighting.
- `--mvo-accent-*` and `--mvo-success` / `--mvo-warning` / `--mvo-danger` / `--mvo-info` map states to functional roles.
- `--mvo-track-*` and `--mvo-meter-*` provide stable data-role colours; any product use remains dependent on real application state.

HEX values are anchors, not instructions to paint entire panels in saturated colour. Keep environmental illumination behind the work surface, preserve opaque-enough editing materials, and use the neutral text tokens for numerical and secondary content.
